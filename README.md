# CivicLens-AI
AI-Powered citizen  complaint classification and prioritisation

Turning Citizen Voices into Prioritised Civic Action.

 About the Project

CivicLens-AI is an AI-powered citizen complaint management and prioritisation system designed to help municipal authorities understand, classify and prioritise public complaints.

Citizens frequently report civic issues such as potholes, overflowing garbage, water leakage, broken streetlights and drainage problems. However, many complaints are unstructured, submitted in different languages and difficult to prioritise manually.

CivicLens-AI transforms these unstructured complaints into organised information using Artificial Intelligence.

 Problem Statement

Municipal departments receive thousands of complaints from citizens. Identifying urgent problems and directing complaints to the correct department can be challenging.

Our solution aims to simplify this process through AI-powered complaint analysis and prioritisation.

 Our Solution

CivicLens-AI analyses citizen complaint descriptions and optional photographs to generate structured complaint information.

The system:

- Accepts complaints in English and regional languages.
- Supports optional complaint photographs.
- Identifies the type of civic issue.
- Assigns an appropriate severity level.
- Generates a one-line explanation for the classification and priority.

Key Features

1. Multilingual Complaint Input

Accepts citizen complaints in English and regional languages.

2. Image Upload

Allows users to attach photographs of civic problems for additional context.

3. AI-Based Complaint Classification

The system identifies six categories:

Category| Example
Roads| Potholes, damaged roads
Waste| Garbage overflow
Water| Water leakage
Electricity| Broken streetlights
Trees| Fallen trees
Drainage| Blocked drains

4. Severity Detection

Each complaint receives one of four severity levels:

- 🟢 Low
- 🟡 Medium
- 🟠 High
- 🔴 Critical

5. AI-Generated Explanation

Provides a short explanation of why the complaint received its category and severity.

6. Structured Complaint Output

Converts unstructured complaints into clear and organised information.

 How It Works

1. Submit: Citizen enters a complaint and optionally uploads a photograph.
2. Interpret: AI understands the complaint description.
3. Classify: AI identifies the appropriate civic issue category.
4. Prioritise: AI assigns a severity level.
5. Explain: The system displays the reason and structured result.

 Workflow

Citizen Input → AI Analysis → Complaint Classification → Severity Detection → Structured Result
